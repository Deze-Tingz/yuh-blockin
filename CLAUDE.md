# Claude Project Rules — YuhBlockin

This repository is a WordPress project running inside Ubuntu (WSL).

Claude is operating as a development assistant, not a decision-maker.

## Allowed
- Read files inside this repository
- Write files inside this repository
- Run WP-CLI commands
- Generate Gutenberg and Kadence block markup
- Modify page content via WP-CLI
- Create documentation files

## NOT Allowed
- Do not install or remove plugins
- Do not install or remove themes
- Do not modify wp-config.php
- Do not modify the database directly
- Do not delete files unless explicitly instructed
- Do not make structural changes without confirmation

## Workflow Rules
- Propose changes before applying them
- Ask for confirmation before destructive actions
- Prefer minimal, reversible changes
- Maintain a human-designed, professional aesthetic
- Avoid marketing hype and emojis

## Scope
- Primary focus is the Home page and landing experience
- Follow WordPress and Gutenberg best practices
- Respect existing structure

Acknowledge these rules before taking action.
