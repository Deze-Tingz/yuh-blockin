>>> Explain this line sudo chown -R www-data:www-data /var/www/html
```
chown -R <user>:<group> <directory>
```

Changes the ownership of the specified directory and all its contents to 
the given user and group.

*   `-R` option is used for recursive operation, meaning it will change 
the ownership of all files and subdirectories within the specified 
directory.
*   `<user>` should be replaced with `www-data`, which is the default 
Apache web server user on most Linux systems.
*   `<group>` should be replaced with `www-data`, which is also the 
default Apache web server group on most Linux systems.
*   `<directory>` should be replaced with `/var/www/html`, which is the 
default directory where WordPress installs its files.

So, in this case, it's changing the ownership of the `/var/www/html` 
directory and all its contents to the `www-data` user and group.

>>> Can i just manually set it to the website and directory in here or isw that not recommended?
```
sudo nano /etc/apache2/sites-available/000-default.conf
```

This will open the default Apache site configuration file.

Look for the `DocumentRoot` directive, which should be set to point to your website's root directory. For example:
```
DocumentRoot /var/www/html
```
Make sure this is set to the correct path, and save and close the file when you're done.

Then, create a new symbolic link to the site configuration file that points to the `sites-enabled` directory:
```
sudo ln -s /etc/apache2/sites-available/000-default.conf /etc/apache2/sites-enabled/
```

This will enable the default site configuration. Finally, restart Apache:
```
sudo service apache2 restart
```

By setting the `DocumentRoot` directive manually, you're telling Apache to serve files from that specific directory. This is a valid approach, but keep in mind that it's generally recommended to use the `DocumentRoot` directive 
within a site configuration file (like `000-default.conf`) rather than hardcoding it directly into the main Apache configuration file.

However, if you're just starting out or need to make some quick adjustments, manually setting the `DocumentRoot` directive can be a good temporary solution.
